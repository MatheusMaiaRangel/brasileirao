# Backend

API responsável pelo gerenciamento dos dados de clubes e jogadores.

## Instalação

Clone o repositório: 

```bash
git clone https://github.com/MatheusMaiaRangel/Trabalho-Fastify-React/
```

Acesse a pasta do backend:

```bash
cd Back
```

Instale as dependências:

```bash
npm install
```

## Executando o Projeto

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Após a inicialização, acesse a URL exibida no terminal da pasta `Front`.
